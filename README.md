# Repositorio de Prácticas para Desarrollo Móvil Integral

Repositorio donde se almacenan las prácticas realizadas durante la materia de **Desarrollo Móvil Integral**, utilizando **Flutter** y **Dart** para el desarrollo de aplicaciones móviles.

## Objetivo

Desarrollar habilidades en la creación de aplicaciones móviles mediante **Flutter**, aplicando conceptos de interfaces, widgets, navegación, funciones, manejo de estados, personalización de estilos y estructura de proyectos.
